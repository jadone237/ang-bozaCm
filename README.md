# BozaCM - Frontend (Angular)

Plateforme de gestion et de réservation de voyages au Cameroun (Bus, Train, Avion).

## Modules
- **Administration** : Gestion des agences, trajets, offres, réservations, statistiques et rapports.
- **Client & Auth** : Inscription, connexion JWT et recherche de voyages.

## Démarrage
```bash
npm install
npm start
